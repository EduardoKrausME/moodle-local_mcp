Conectar o ChatGPT

Conecte seu Moodle ao ChatGPT pelo protocolo MCP. O guia mostra a configuração OAuth, a URL do servidor e as permissões necessárias para consultar cursos e executar operações autorizadas.

Como funciona

Instale o plugin local_mcp na pasta local/mcp, conclua a atualização do Moodle e abra Administração do site → Plugins locais → Moodle MCP → Conexões. O painel apresenta um guia visual para configurar o ChatGPT com OAuth, incluindo os valores que devem ser utilizados no cadastro do servidor MCP.

No ChatGPT, adicione um servidor MCP personalizado e informe o endereço https://SEU-MOODLE/local/mcp/server.php. Configure a autenticação por OAuth e o registro dinâmico de clientes (DCR). O ícone PNG apresentado no guia pode ser usado para identificar a integração.

Conclua o login pelo Moodle e autorize o escopo mcp:read para consultas e, quando necessário, mcp:write para operações administrativas. O servidor também verifica as permissões do usuário em cada operação. Depois de instalar ou atualizar ferramentas MCP, reconecte o cliente para atualizar a listagem de ferramentas disponíveis.

Conectando em cinco etapas

  1. Prepare o Moodle. Instale local_mcp, finalize a atualização, configure uma URL pública HTTPS em $CFG->wwwroot, habilite Dynamic Client Registration (DCR) nas configurações do plugin e verifique a descoberta OAuth indicada abaixo. O consentimento exige uma conta de administrador com moodle/site:config.
  2. Copie o endereço do servidor. Abra a administração do Moodle MCP em /local/mcp/admin/connections.php e copie a URL exibida. O formato é https://SEU-MOODLE/local/mcp/server.php, incluindo um eventual subdiretório do Moodle, sem parâmetros de token.
  3. Cadastre no ChatGPT. Em chatgpt.com, abra Plugins e escolha adicionar um servidor MCP personalizado. Informe nome (por exemplo, Moodle MCP), descrição e ícone PNG opcionais, selecione Server URL (não Tunnel), cole a URL e selecione OAuth com descoberta automática e DCR. Os rótulos podem variar conforme a versão do ChatGPT.
  4. Autorize o acesso. Leia o aviso de segurança, conclua a criação e faça login no Moodle quando solicitado. Confira o aplicativo e os escopos: mcp:read permite consultar dados; mcp:write permite solicitar alterações, sempre sujeitas às permissões Moodle e à confirmação de operações WRITE.
  5. Teste e atualize. Em uma conversa com o plugin, peça: “Liste os cursos que consigo consultar neste Moodle.” Se instalar novos provedores ou ferramentas, atualize a conexão no ChatGPT para recarregar tools/list.

Configurando a descoberta OAuth

O ChatGPT precisa consultar https://SEU-MOODLE/.well-known/oauth-authorization-server/local/mcp e receber metadados JSON. A URL não é criada automaticamente pelo plugin, portanto configure uma regra de rewrite no servidor web, adaptando os caminhos se o Moodle não estiver instalado na raiz do domínio.

Apache:

RewriteRule ^\.well-known/oauth-authorization-server/local/mcp$ local/mcp/.well-known/oauth-authorization-server.php [L]

Nginx:

location = /.well-known/oauth-authorization-server/local/mcp {
    rewrite ^ /local/mcp/.well-known/oauth-authorization-server.php last;
}

Consulte a documentação de OAuth e descoberta e a configuração completa do servidor web.

Problemas frequentes

  • OAuth discovery failed / 404: verifique o rewrite, o HTTPS, o $CFG->wwwroot e a resposta JSON da URL de descoberta.
  • Registro de cliente recusado: habilite o DCR nas configurações do Moodle MCP.
  • 401 sem autenticação: o endpoint MCP exige bearer token OAuth; esse status é esperado sem autorização, e tokens nunca devem ser enviados por ?token=.
  • 403 ou ferramentas ausentes: confira os escopos READ/WRITE e as capacidades do usuário Moodle; OAuth não amplia permissões.
  • Ferramentas novas não aparecem: conclua a atualização do Moodle, limpe o cache e atualize a conexão no ChatGPT.
Para utilizar OAuth, publique o Moodle com HTTPS, habilite o registro dinâmico de clientes e configure o rewrite da URL de descoberta /.well-known/oauth-authorization-server/local/mcp no servidor web.
