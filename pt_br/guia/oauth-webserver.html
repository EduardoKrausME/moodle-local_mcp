OAuth e configuração do servidor web

Regras Apache/Nginx, descoberta OAuth e PKCE.

O emissor OAuth do local_mcp é https://SEU-MOODLE/local/mcp, e clientes MCP compatíveis com os padrões precisam conseguir consultar:

https://SEU-MOODLE/.well-known/oauth-authorization-server/local/mcp

Plugins Moodle não conseguem registrar rotas fora do diretório da plataforma. Portanto, configure uma regra de reescrita no servidor web para encaminhar a URL de descoberta aos metadados de autorização do plugin.

Apache

Na configuração de rewrite da raiz do site Moodle:

RewriteEngine On
RewriteRule ^\.well-known/oauth-authorization-server/local/mcp$ local/mcp/.well-known/oauth-authorization-server.php [L]

Nginx

Dentro do virtual host do Moodle:

location = /.well-known/oauth-authorization-server/local/mcp {
    rewrite ^ /local/mcp/.well-known/oauth-authorization-server.php last;
}

Se o Moodle estiver instalado em um subdiretório, adapte ambas as URLs, incluindo o prefixo do subdiretório. Não redirecione a requisição para um emissor diferente do campo issuer fornecido pelo endpoint.

Verificação e conexão

Depois de aplicar a configuração, confirme que a URL de descoberta retorna metadados válidos do Authorization Server. Em seguida, habilite o registro dinâmico de clientes nas configurações do plugin e conecte o cliente MCP a https://SEU-MOODLE/local/mcp/server.php, sempre com HTTPS. Conclua o login normal do Moodle e o consentimento do administrador.

Segurança: o OAuth utiliza Authorization Code com PKCE S256; o cliente precisa informar o parâmetro resource associado ao endpoint. Não inclua tokens OAuth nos parâmetros da URL.

Para instruções ilustradas de configuração, consulte o guia de OAuth em português ou a versão em inglês.
