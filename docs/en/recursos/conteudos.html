Courses, activities and questions

Create and maintain Moodle learning content through typed tools that respect Moodle module lifecycles and native permissions.

How it works

Use list_categories to identify target categories, then create_category, create_course, create_section and update_course as needed. bulk_create_courses accepts up to 30 courses per request and can skip existing courses rather than overwriting them.

Activity subplugins provide operations for pages, forums, books, files, H5P, URLs, labels, quizzes and glossaries. File uploads use the Moodle File API; course cover images can be supplied as Base64 or via a server-accessible HTTPS URL.

For question banks, start with list_question_banks and list_question_categories, then use search_questions and get_question. WRITE tools create_question_category, create_question and update_question respect contexts and question versioning, with preview and confirmation for changes.

Remote Moodle cannot read your local filesystem or private client image URLs. Send Base64 file bytes or a truly accessible HTTPS URL, within each tool's size limits.
