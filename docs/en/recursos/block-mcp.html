MCP block for teachers

Connect individual ChatGPT accounts to Moodle courses through the MCP block with teaching permissions and confirmation checks.

The block_mcp plugin lets authorized teachers and course managers connect their own ChatGPT accounts to Moodle from a course, without sharing credentials or gaining extra administrative privileges.

Installation and requirements

  1. Install local_mcp version 2026112000 or later and block_mcp under blocks/mcp, upgrade Moodle and add the block to a course.
  2. Apply the teacher authorization integration patch described in the block README. The original local_mcp OAuth endpoint requires moodle/site:config and would reject non-admin teachers.
  3. Grant block/mcp:teach and block/mcp:use only to appropriate roles and enable and configure the block for the course.
  4. From a ChatGPT account supporting custom MCP connections, authorize /local/mcp/server.php using the teacher's own Moodle account.
WRITE tools are disabled by default and require confirmation. The block must be enabled and visible, Moodle capabilities are checked again for each operation, and students cannot use teacher tools even if legacy audience settings are broad.

Available capabilities

Reading tools include block_mcp_get_study_content, block_mcp_get_my_tasks and block_mcp_get_my_grades. Other operations are governed by tool allowlists and course-specific settings.

Try asking

“Review the resources and activities in my course and help me plan the next lesson.”
“Show the tasks I can access and suggest a course follow-up plan.”

Security and deployment

Teachers and managers need course access and the block capabilities. Non-enrolled managers can also use it when they have moodle/course:view. Unknown tools, unauthorized contexts and administrative operations are denied to educational users.

Isolated tests have been performed, but full integration on Moodle 4.5/5.x and CI results must still be checked before production deployment.
