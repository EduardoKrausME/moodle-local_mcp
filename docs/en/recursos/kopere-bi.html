Kopere BI + Moodle MCP

Explore Moodle reports directly in ChatGPT.

With Kopere BI and Moodle MCP installed, ChatGPT can discover the reports available to the connected account, retrieve structured rows, and help analyze enrolments, grades, activity and course performance without manually exporting every report.

How to use it

  1. Install and configure Kopere BI and local_mcp on the same Moodle site.
  2. Connect ChatGPT to /local/mcp/server.php and grant READ access.
  3. Refresh the connection and call kopere_bi_list_reports to list accessible report names, categories, stable refkey values and tool identifiers.
  4. Run the selected kopere_bi_report_<refkey> tool, optionally specifying course_id, user_id, limit and offset.

Try asking

“List my available Kopere BI reports, find those about engagement and performance, and compare the selected course results in charts and tables.”
“Read the enrolment report and summarize trends that could explain declining participation.”

What comes back

Each report returns structured results for SQL-backed charts, KPIs and tables, with pagination per item. Tool names use each report's stable refkey, never its internal database ID.

Users can only query reports they are allowed to access. Filtering another user or a cohort requires BI management permissions, and reports without a unique valid refkey are not exposed.
