Conectar o ChatGPT

Configure a primeira conexão MCP a partir do Moodle e escolha entre um token temporário de teste e a autenticação OAuth recomendada para produção.

Como funciona

Instale o plugin local_mcp na pasta local/mcp, conclua a atualização do Moodle e abra Administração do site → Plugins locais → Moodle MCP → Conexões. Clique em Nova conexão, escolha um nome e selecione READ; habilite WRITE somente quando precisar permitir alterações.

A conexão manual fornece uma URL completa no formato https://SEU-MOODLE/local/mcp/server.php?toke=mcp_... . Copie a URL enquanto ela estiver visível: o segredo não é recuperado em texto puro depois. Em um cliente MCP compatível, cadastre essa URL com a opção sem autenticação.

O token de teste possui expiração de sete dias, pode ser revogado e é associado ao administrador que o criou. A opção Editar permissões permite mudar os escopos de uma conexão manual ativa sem alterar sua URL. Reconecte o cliente quando houver mudanças na lista de ferramentas.

Tokens em parâmetros de URL podem aparecer em logs de proxy e servidor. Use HTTPS, não divulgue a URL e prefira OAuth para conexões duradouras.
