Core tool catalog

Reference to all MCP tools registered directly by local_mcp.

Inventory checked against master branch registries: 39 READ tools and 33 WRITE tools. The server may additionally discover tools from enabled subplugins and external providers; they are not included here.

Get the exact input schema, capability and current availability from tools/list on the connected server, or from the administrative READ/WRITE API pages. Some tools require administrator or module-specific permissions.

WRITE safety

mcp:write does not imply mcp:read. WRITE tools use an explicit preview and single-use confirmation bound to arguments, user, client, context and connection. See specific guides, sequential workflows and administration for usage details.
