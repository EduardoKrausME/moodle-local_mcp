Glossaries

Create Glossary activities and add HTML-defined entries.

This subplugin registers READ and/or WRITE MCP tools only when installed and enabled in Moodle. OAuth scopes never replace Moodle capabilities.

Available tools

ToolModePurposeMain parametersMoodle capability
glossary_create_activityWRITECreate Glossary with duplicate, approval and comment options.courseid, sectionnum, name, intro, allowduplicatedentries, defaultapproval, allowcommentsmoodle/course:manageactivities
glossary_create_entryWRITECreate an entry with concept and HTML definition.cmid, concept, definitionmod/glossary:write

Parameter names show relevant inputs, not necessarily all required inputs. Consult tools/list on the connected installation for full schemas and optional fields.

Rules, limits and security

Activity creation uses Moodle add_moduleinfo() and also requires module add-instance permission. Review concepts, definitions and activity settings before confirming.

WRITE tools enforce capability checks, a no-write preview and explicit confirmation before execution. Refresh MCP tool discovery after updating the plugin or its subplugins.
