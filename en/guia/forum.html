Forums and discussions

Create forums, list discussions, read posts and publish topics or replies.

This subplugin registers READ and/or WRITE MCP tools only when installed and enabled in Moodle. OAuth scopes never replace Moodle capabilities.

Available tools

ToolModePurposeMain parametersMoodle capability
forum_list_discussionsREADList visible forum discussions.cmid, limitmod/forum:viewdiscussion
forum_get_postsREADRead posts with group and per-post visibility checks.discussionid, limit, offsetmod/forum:viewdiscussion
forum_create_activityWRITECreate a Forum activity in a course section.courseid, sectionnum, name, intromoodle/course:manageactivities
forum_create_discussionWRITEStart a topic in a standard forum with confirmation.cmid, subject, message, groupidmod/forum:startdiscussion
forum_reply_to_postWRITEReply to a post as the authenticated user.postid, message, subjectmod/forum:replypost

Parameter names show relevant inputs, not necessarily all required inputs. Consult tools/list on the connected installation for full schemas and optional fields.

Rules, limits and security

Post visibility follows Moodle capabilities and group restrictions. New discussions and replies use the connected Moodle user's identity and require confirmed previews.

WRITE tools enforce capability checks, a no-write preview and explicit confirmation before execution. Refresh MCP tool discovery after updating the plugin or its subplugins.
