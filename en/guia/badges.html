Badges

Create, illustrate, configure completion criteria and enable site/course badges.

This subplugin registers READ and/or WRITE MCP tools only when installed and enabled in Moodle. OAuth scopes never replace Moodle capabilities.

Available tools

ToolModePurposeMain parametersMoodle capability
badges_image_guideREADGuidance for compatible PNG badge artwork.courseidmoodle/badges:viewbadges
badges_listREADList site or course badges before creating duplicates.courseidmoodle/badges:viewbadges
badges_getREADRead status, image, award count and modification timestamp.badgeidmoodle/badges:viewbadges

badges_set_criteriaWRITESet ALL-of selected activity-completion criteria for course badges.badgeid, expected_timemodified, cmidsmoodle/badges:configurecriteria
badges_enableWRITEEnable course badge for Moodle-managed awards after criteria checks.badgeid, expected_timemodifiedmoodle/badges:configurecriteria

Parameter names show relevant inputs, not necessarily all required inputs. Consult tools/list on the connected installation for full schemas and optional fields.

Rules, limits and security

Square transparent PNG, 256–1024 pixels, up to 256 KiB. Use one image source. Creating a badge does not enable it; automatic activity completion must be configured before setting ALL-of criteria. Enabling may trigger Moodle awards via events/cron. All WRITE operations require preview and confirmation.

WRITE tools enforce capability checks, a no-write preview and explicit confirmation before execution. Refresh MCP tool discovery after updating the plugin or its subplugins.
