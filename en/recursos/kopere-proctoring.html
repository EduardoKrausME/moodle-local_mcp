Kopere Proctoring + Moodle MCP

Review Kopere Proctoring attempts, events and settings in ChatGPT or Claude through MCP, preserving permissions and human review.

Kopere Proctoring and Moodle MCP together let authorized users check quiz monitoring settings, list monitored attempts and analyze events captured during online assessments. Quiz managers can also request enabling or disabling monitoring through the normal approval flow.

How to use it

  1. Install Kopere Proctoring and Moodle MCP on the same Moodle site.
  2. Connect ChatGPT with READ access, and WRITE only if you manage quizzes.
  3. Provide the quiz course-module ID (cmid) and use kopere_proctoring_get_quiz and kopere_proctoring_list_attempts.
  4. Use kopere_proctoring_get_attempt_logs with cmid and attemptid to review events; technical data such as IP addresses is omitted by default.
  5. Call kopere_proctoring_set_quiz_enabled to change monitoring, review the preview, and confirm. Pass the previously returned state_hash as expected_hash to detect concurrent changes.

Try asking

“Check whether monitoring is enabled for quiz cmid 456, and summarize the recorded attempts and event counts.”
“Build a timeline of monitoring events for attempt 789 in quiz 456, highlighting items that need human review rather than concluding misconduct.”

Available operations

The provider exposes kopere_proctoring_list_policies, kopere_proctoring_get_quiz, kopere_proctoring_list_attempts, kopere_proctoring_get_attempt_logs, and the WRITE tool kopere_proctoring_set_quiz_enabled. Enabling monitoring preserves individual policy flags, while setting quiz questionsperpage to 50 as the plugin settings form does.

Monitoring events are observations, not automatic evidence of misconduct. Interpret them with institutional policies, privacy requirements and human review.
