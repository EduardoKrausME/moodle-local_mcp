Helpdesk + Moodle MCP

Handle support tickets without leaving ChatGPT.

The Helpdesk MCP provider can search tickets, read conversations, find knowledge-base articles, and prepare replies. When WRITE is authorized, users with the necessary Moodle capabilities can create tickets, respond, change their status or publish help articles.

How to use it

  1. Install Helpdesk and Moodle MCP on the same site.
  2. Connect ChatGPT via /local/mcp/server.php with READ access and optionally WRITE access.
  3. Refresh discovery; use helpdesk_list_tickets, helpdesk_ticket_stats or helpdesk_list_articles to investigate issues.
  4. Open a ticket using helpdesk_get_ticket; draft a reply with helpdesk_reply_ticket or request a status change with helpdesk_update_ticket, then confirm the preview.

Try asking

“List urgent open Helpdesk tickets and group them by priority so we can decide what to address first.”
“Read ticket 123 and find related knowledge-base guidance. Draft a response but send it only after I approve.”

Available operations

READ: helpdesk_list_tickets, helpdesk_get_ticket, helpdesk_list_categories, helpdesk_list_articles and helpdesk_ticket_stats. WRITE: helpdesk_create_ticket, helpdesk_reply_ticket, helpdesk_update_ticket and helpdesk_create_article.

Regular users can only see their own tickets. Support-wide queries, ticket administration and article creation require additional Moodle capabilities. Ticket creation and replies may trigger normal email notifications.
