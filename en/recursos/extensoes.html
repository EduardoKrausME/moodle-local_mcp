Install plugins and give AI more capabilities

Install Moodle plugins compatible with MCP to expand what ChatGPT or Claude can do, without writing code.

How it works

Install Moodle MCP and any other compatible plugins your institution needs. Enable and configure each plugin in Moodle as usual.

The integration automatically recognizes the features made available by compatible plugins. Refresh the connection in ChatGPT or Claude so the newly available actions can be used in the conversation.

For example, you can analyze Kopere BI reports, manage Helpdesk tickets or review Kopere Proctoring data, depending on the installed plugins and your account permissions.

Automatic discovery applies to compatible plugins and does not grant additional privileges. Changes to Moodle data still require confirmation.
