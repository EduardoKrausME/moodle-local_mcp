Import courses from Excel into Moodle with ChatGPT

Turn spreadsheet rows into courses with categories, short names and HTML summaries, without opening every course form.

Copy ready-to-use prompt ↓How it works ↓
Real-world situation

A school sends its next semester's subjects in an XLSX file with code, title, category and description.

Before you start

Connect Moodle to ChatGPT or Claude with appropriate permissions. To create or change data, the connection needs WRITE access and the signed-in user must have the relevant Moodle capabilities. Connection guide →

Step by step

  1. Attach Excel and ask for a preview of parsed columns, including incomplete or invalid rows.
  2. Verify category IDs, unique course codes, HTML summaries and whether courses must remain hidden.
  3. Use bulk_create_courses with at most 30 entries per batch, skip_existing and duplicate detection.
  4. Approve each batch preview and check created IDs, skipped rows and errors before moving on.

Ready-to-use ChatGPT or Claude prompt

Copy the prompt, edit course names and attach relevant files. The assistant is asked to show its plan before writing to Moodle.

Example prompt
My Excel file has columns code, subject, category and description. Read every row and show a validation table. Never invent missing values. Check categories and existing courses in Moodle by short name or idnumber. Prepare only new courses, initially hidden, with HTML summaries based on the descriptions, using bulk_create_courses in batches of up to 30. Show the official preview for each batch and wait for my approval. Summarize created, skipped and failed rows.

Tools used in this workflow

ChatGPT or Claude selects the tools exposed by the connected installation. These tool names exist in the plugin and are relevant to this example:

list_categoriessearch_coursesbulk_create_coursesget_course

View tool reference and parameters →

How to verify the result

Reconcile valid spreadsheet rows against created, skipped and failed results; open sample courses to confirm codes and categories.

Limitations and safeguards

ChatGPT reads the XLSX file; local_mcp does not offer a direct XLSX-upload tool. bulk_create_courses is limited to 30 courses per call, never edits existing courses and requires HTML summaries.

Protected WRITE operations show a preview and execute only after explicit confirmation. If the assistant cannot access a tool, it must report that limitation instead of claiming it published content.
