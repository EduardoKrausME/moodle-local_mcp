Turn a PDF into a Moodle course with ChatGPT

Upload learning material, review a course outline and publish sections and activities after approving the changes.

Copy ready-to-use prompt ↓How it works ↓
Real-world situation

You have received a training manual and need to turn it into a navigable course without copying every chapter into Moodle.

Before you start

Connect Moodle to ChatGPT or Claude with appropriate permissions. To create or change data, the connection needs WRITE access and the signed-in user must have the relevant Moodle capabilities. Connection guide →

Step by step

  1. Attach the PDF or document and ask ChatGPT to verify that its text is readable.
  2. Request a course outline with learning goals, an HTML summary, sections and activities, without publishing yet.
  3. Identify the destination category, check for existing courses and review names, workload and visibility.
  4. Approve each official preview, then check which courses, sections and activities were actually created.

Ready-to-use ChatGPT or Claude prompt

Copy the prompt, edit course names and attach relevant files. The assistant is asked to show its plan before writing to Moodle.

Example prompt
Read the attached PDF and propose a beginner training course with learning outcomes, five modules, practical explanations and one activity per module. Show the full outline first without changing Moodle. After my approval, connect to Moodle, verify the destination category and create the course as hidden, along with its sections and HTML pages. Show the official preview before each write and await my approval. Return the actual URLs created.

Tools used in this workflow

ChatGPT or Claude selects the tools exposed by the connected installation. These tool names exist in the plugin and are relevant to this example:

search_courseslist_categoriescreate_coursecreate_sectionpage_create_activitybook_create_activity

View tool reference and parameters →

How to verify the result

Open the returned course URL, review its section order, activity links and visibility before enabling it for students.

Limitations and safeguards

The PDF is read by ChatGPT, not imported through a native PDF tool in local_mcp. Scanned documents may need conversion; review content, images and copyright.

Protected WRITE operations show a preview and execute only after explicit confirmation. If the assistant cannot access a tool, it must report that limitation instead of claiming it published content.
