Manage cohorts and synchronize enrolments using ChatGPT

Build audiences for several courses without confusing site cohorts with individual course groups.

Copy ready-to-use prompt ↓How it works ↓
Real-world situation

New employees should automatically gain access to the common courses for their department.

Before you start

Connect Moodle to ChatGPT or Claude with appropriate permissions. To create or change data, the connection needs WRITE access and the signed-in user must have the relevant Moodle capabilities. Connection guide →

Step by step

  1. Confirm mcptool_cohort and Moodle cohort enrolment are available.
  2. Search existing cohorts and propose a distinct, clearly identified cohort.
  3. Add members in batches of up to 50 after reading a fresh membership hash.
  4. Link the cohort to courses via cohort enrolment, approve previews and validate actual membership and enrolments.

Ready-to-use ChatGPT or Claude prompt

Copy the prompt, edit course names and attach relevant files. The assistant is asked to show its plan before writing to Moodle.

Example prompt
I need an onboarding cohort for new employees. Search existing Moodle cohorts and propose one called Onboarding 2026 without duplicates. I will supply the verified learner list and destination courses. After approval, prepare cohort creation, member additions using a current expected_members_sha256, and cohort enrolment links using cohort_enrol_cohort. Show official previews before writes and report real cohort IDs and verified enrolments.

Tools used in this workflow

ChatGPT or Claude selects the tools exposed by the connected installation. These tool names exist in the plugin and are relevant to this example:

cohort_search_cohortscohort_create_cohortcohort_get_cohort_memberscohort_add_cohort_memberscohort_enrol_cohort

View tool reference and parameters →

How to verify the result

Check cohort members and course cohort-enrolment instances; synchronization depends on the native Moodle enrolment method.

Limitations and safeguards

Requires the optional mcptool_cohort subplugin and enrol_cohort availability. Native spreadsheet cohort import and arbitrary editing of externally managed enrolment instances are not supported.

Protected WRITE operations show a preview and execute only after explicit confirmation. If the assistant cannot access a tool, it must report that limitation instead of claiming it published content.
