Generate questions with AI and build a Moodle quiz

Create feedback-rich questions, organize a question bank and assemble an assessment with answer review.

Copy ready-to-use prompt ↓How it works ↓
Real-world situation

You have source material for a formative assessment but need to review every question before publishing.

Before you start

Connect Moodle to ChatGPT or Claude with appropriate permissions. To create or change data, the connection needs WRITE access and the signed-in user must have the relevant Moodle capabilities. Connection guide →

Step by step

  1. Ask for questions grounded in the material, plausible distractors, an answer key and response feedback.
  2. Review content and difficulty, then locate the correct question bank and category.
  3. Import GIFT text using import_gift_question_bank, create a quiz and add ready questions.
  4. Approve each preview and test the quiz as a teacher before enabling attempts.

Ready-to-use ChatGPT or Claude prompt

Copy the prompt, edit course names and attach relevant files. The assistant is asked to show its plan before writing to Moodle.

Example prompt
Based on the attached material, create 15 multiple-choice questions with one correct answer, three plausible distractors and pedagogical feedback. Show all questions and the answer key for review first. After I approve, locate the course question bank and prepare a GIFT import using import_gift_question_bank. Then propose a 20-minute quiz and add only confirmed ready questions. Show official write previews and await my approval at every step. Return the created Moodle links and outcomes.

Tools used in this workflow

View tool reference and parameters →

How to verify the result

Check question categories, ready status, total marks and attempts, and run a test attempt.

Limitations and safeguards

GIFT import accepts up to 500 questions and 2 MiB of text per call, with restrictions on category directives and question types. AI-produced answer keys must be checked by a teacher.

Protected WRITE operations show a preview and execute only after explicit confirmation. If the assistant cannot access a tool, it must report that limitation instead of claiming it published content.
