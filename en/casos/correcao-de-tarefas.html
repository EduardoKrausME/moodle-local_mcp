Use ChatGPT to assist Moodle assignment marking

Review submissions, draft constructive feedback and record marks only after teacher approval.

Copy ready-to-use prompt ↓How it works ↓
Real-world situation

A class submitted written work and the teacher wants consistent feedback without delegating final assessment to AI.

Before you start

Connect Moodle to ChatGPT or Claude with appropriate permissions. To create or change data, the connection needs WRITE access and the signed-in user must have the relevant Moodle capabilities. Connection guide →

Step by step

  1. Read the accessible feedback queue and submission context.
  2. Analyze only documents actually extractable by the tool and suggest feedback aligned to a marking guide.
  3. The teacher reviews each suggestion and prepares a mark/feedback write using current submission state.
  4. Approve the preview, confirm the write and handle grade release separately if needed.

Ready-to-use ChatGPT or Claude prompt

Copy the prompt, edit course names and attach relevant files. The assistant is asked to show its plan before writing to Moodle.

Example prompt
For the assignment I choose, read the marking queue I am permitted to access and summarize pending submissions. For each readable submission, draft constructive feedback based on my criteria, but do not assign a final grade automatically. Wait for my review. Only then prepare assign_save_grade_and_feedback for specifically approved cases, using the required current revision data and official preview. Do not release grades without a separate request.

Tools used in this workflow

ChatGPT or Claude selects the tools exposed by the connected installation. These tool names exist in the plugin and are relevant to this example:

get_assignment_feedback_queueget_assignment_feedback_contextassign_get_submission_documentassign_save_grade_and_feedbackassign_release_grades

View tool reference and parameters →

How to verify the result

Compare confirmed saves against pending submissions, inspect marks and grade visibility, and retain teacher accountability for assessment.

Limitations and safeguards

PDF extraction requires a supported server-side converter and size limits apply. Group submissions, anonymous grading and rubrics have additional restrictions and may require Moodle UI actions.

Protected WRITE operations show a preview and execute only after explicit confirmation. If the assistant cannot access a tool, it must report that limitation instead of claiming it published content.
