Organize course groups and allocate learners with ChatGPT

Create groups, plan membership and keep group allocation under control.

Copy ready-to-use prompt ↓How it works ↓
Real-world situation

A course has 120 learners and needs four groups for activities led by different tutors.

Before you start

Connect Moodle to ChatGPT or Claude with appropriate permissions. To create or change data, the connection needs WRITE access and the signed-in user must have the relevant Moodle capabilities. Connection guide →

Step by step

  1. Read existing groups and accessible course participants while respecting separate-group restrictions.
  2. Propose a balanced distribution and ensure all users are actively enrolled.
  3. Create missing groups and retrieve current membership with get_group_members.
  4. Call add_group_members in batches of up to 50 IDs, using a fresh expected_members_sha256, confirm and reconcile.

Ready-to-use ChatGPT or Claude prompt

Copy the prompt, edit course names and attach relevant files. The assistant is asked to show its plan before writing to Moodle.

Example prompt
For the course I select, retrieve groups and learners I am allowed to see. Propose four balanced groups without changing Moodle. After approval, create only missing groups, then add already-enrolled learners, reading get_group_members for a fresh expected_members_sha256 before each change. Show each official preview and wait for my permission. Finish with actual member counts and learners not assigned to any group.

Tools used in this workflow

ChatGPT or Claude selects the tools exposed by the connected installation. These tool names exist in the plugin and are relevant to this example:

get_course_groupsget_group_memberscreate_groupadd_group_membersremove_group_members

View tool reference and parameters →

How to verify the result

Compare active enrolments with group member counts and account for learners who may belong to multiple groups.

Limitations and safeguards

Course groups are not site-wide cohorts. Adding members requires active enrolment, a current membership hash and the right Moodle permissions.

Protected WRITE operations show a preview and execute only after explicit confirmation. If the assistant cannot access a tool, it must report that limitation instead of claiming it published content.
