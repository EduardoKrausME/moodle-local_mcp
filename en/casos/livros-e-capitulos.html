Build a complete Moodle Book with ChatGPT

Design a table of contents, chapter activities and navigation before publishing a structured Moodle Book.

Copy ready-to-use prompt ↓How it works ↓
Real-world situation

A teacher has scattered lesson notes and wants a consistent resource with chapters and subchapters.

Before you start

Connect Moodle to ChatGPT or Claude with appropriate permissions. To create or change data, the connection needs WRITE access and the signed-in user must have the relevant Moodle capabilities. Connection guide →

Step by step

  1. Attach material and ask for an outline with chapters, subchapters and learning goals.
  2. Review the HTML, sources, illustrations and activities for copyright and accessibility.
  3. Create the Book through book_create_activity and publish chapters with book_create_chapter.
  4. Read the final order using book_list_chapters and review links; edits require expected_revision.

Ready-to-use ChatGPT or Claude prompt

Copy the prompt, edit course names and attach relevant files. The assistant is asked to show its plan before writing to Moodle.

Example prompt
Organize the attached materials into a Moodle Book containing six chapters, short practical examples and a review exercise at the end of each chapter. Show the outline and chapter drafts first. After approval, create the Book in my selected course section and add chapters using book_create_chapter. Show an official preview before every write, do not duplicate existing content, and finish by checking chapter names, order and actual Moodle links.

Tools used in this workflow

ChatGPT or Claude selects the tools exposed by the connected installation. These tool names exist in the plugin and are relevant to this example:

book_create_activitybook_create_chapterbook_list_chaptersbook_get_chapterbook_update_chapter

View tool reference and parameters →

How to verify the result

Check the Book table of contents, chapter navigation and final HTML; do not count unapproved chapters as published.

Limitations and safeguards

The Moodle Book activity and its optional tool provider must be installed. Editing an existing chapter requires an up-to-date expected_revision.

Protected WRITE operations show a preview and execute only after explicit confirmation. If the assistant cannot access a tool, it must report that limitation instead of claiming it published content.
