Publish an interactive H5P activity to Moodle from ChatGPT

Plan an interactive experience and upload a valid H5P package as a course activity.

Copy ready-to-use prompt ↓How it works ↓
Real-world situation

A teacher needs drag-and-drop questions, an interactive presentation or a video quiz.

Before you start

Connect Moodle to ChatGPT or Claude with appropriate permissions. To create or change data, the connection needs WRITE access and the signed-in user must have the relevant Moodle capabilities. Connection guide →

Step by step

  1. Request a pedagogical flow and select an H5P content type supported by the installation.
  2. Prepare or supply an actual valid .h5p file compatible with the Moodle H5P libraries.
  3. Identify a section and pass the real package as Base64 to h5p_create_activity; inspect package validation.
  4. Approve the write and test the activity as both teacher and student.

Ready-to-use ChatGPT or Claude prompt

Copy the prompt, edit course names and attach relevant files. The assistant is asked to show its plan before writing to Moodle.

Example prompt
Help me design an H5P first-aid revision activity. Propose the sequence of interactions, questions and feedback first. Do not claim to have generated a .h5p package from text alone. Once I supply or approve a compatible H5P package, prepare h5p_create_activity in my chosen Moodle section using valid filename and file_base64. Show the official preview before publishing, then return the real URL and a functionality checklist.

Tools used in this workflow

ChatGPT or Claude selects the tools exposed by the connected installation. These tool names exist in the plugin and are relevant to this example:

h5p_create_activityget_course_activities

View tool reference and parameters →

How to verify the result

Open the published activity and test all interactive elements and grading or tracking where supported.

Limitations and safeguards

The tool requires a real Base64-encoded .h5p ZIP file, up to 40 MiB. local_mcp does not automatically turn a text prompt into a working H5P package.

Protected WRITE operations show a preview and execute only after explicit confirmation. If the assistant cannot access a tool, it must report that limitation instead of claiming it published content.
